# Web Portfolio

เว็บพอร์ตโฟลิโอภาษาไทยแบบหน้าเดียว รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์ พร้อมนำขึ้น Vercel

## ข้อมูลที่ควรเปลี่ยนก่อนเผยแพร่

แก้ไขใน `app/page.tsx`:

- `YOUR NAME` และอักษรย่อ `YN`
- ประวัติ การศึกษา ทักษะ และประสบการณ์
- รายละเอียดโปรเจกต์และเครื่องมือที่ใช้จริง
- ใบรับรองและกิจกรรม
- `your.email@example.com`
- ลิงก์ GitHub, LinkedIn และ Twitter / X
- เปลี่ยนพื้นที่รูปโปรไฟล์เป็นรูปของคุณเมื่อพร้อม

แก้ไขชื่อและคำอธิบายของเว็บไซต์ใน `app/layout.tsx`

## เปิดดูบนเครื่อง

1. ติดตั้ง Node.js เวอร์ชัน 22 ขึ้นไป
2. รัน `npm install`
3. รัน `npm run dev`
4. เปิด `http://localhost:3000`

## นำขึ้น Vercel

1. เข้าสู่ระบบที่ Vercel
2. สร้างโปรเจกต์ใหม่และอัปโหลดโฟลเดอร์นี้ หรือเชื่อมต่อ GitHub repository
3. Vercel จะตรวจพบ Next.js และตั้งค่าการสร้างเว็บให้อัตโนมัติ
